## 채널에서 시간으로 이어지는 두 단계

```mermaid
flowchart LR
 X[입력 특징] --> C[채널별 계수 곱하기]
 C --> T[시점별 계수 곱하기]
 T --> Y[출력 특징]
```

1D 구현에서 채널 계수는 $1\times C$, 시간 계수는 $T\times1$이다. $T$는 시점 수, $C$는 채널 수다. 먼저 채널 계수를 곱한 특징에서 시간 계수를 계산한다. 이미지에서는 시간 축 대신 높이와 너비로 공간 계수를 만든다.

### 1. CBAM은 무엇을 위해 제안된 모듈인가?

기존 CNN 특징 맵에 작은 모듈을 붙여 입력별로 유용한 특징과 위치를 순차적으로 강조하려고 제안됐다. 이미지 인식 모델에 삽입해 효과를 비교했다.

### 2. CBAM은 어떤 두 가지 attention으로 구성되어 있는가?

먼저 채널 attention으로 특징 종류별 비중을 정하고, 그 결과에 spatial attention을 적용해 위치별 비중을 정한다. 두 단계 모두 원래 특징에 가중치를 곱한다.

### 3. Channel Attention Module은 무엇을 학습하는가?

입력 전체를 평균·최대로 요약한 뒤 채널별 계수를 만드는 함수를 학습한다. 학습이 끝난 뒤에도 새 이미지가 들어오면 계수는 새로 계산된다.

### 4. Spatial Attention Module은 무엇을 학습하는가?

채널을 요약한 특징 맵에 합성곱을 적용해 각 위치에 줄 계수를 학습한다. 1D 행동 인식에 대응시키면 각 시점의 가중치를 만드는 연산이다.

### 5. Channel attention과 spatial attention의 차이는 무엇인가?

채널 attention은 같은 특징 맵 전체에 공통 계수를 곱하고, spatial attention은 같은 위치의 모든 채널에 공통 계수를 곱한다. 앞쪽은 ‘어떤 특징’, 뒤쪽은 ‘어디에서 나타난 특징’을 다룬다.

### 6. CBAM에서 channel attention을 계산할 때 Global Average Pooling과 Global Max Pooling을 함께 사용하는 이유는 무엇인가?

국소적으로만 강하게 나타나는 신호는 평균만 보면 약해질 수 있다. 평균과 최댓값을 각각 같은 MLP에 통과시킨 뒤 두 출력을 더해 일상적인 반응과 두드러진 반응을 함께 반영한다.

### 7. GAP은 어떤 정보를 반영하고, GMP는 어떤 정보를 반영하는가?

반응이 [0, 0, 0, 8]이면 GAP은 2, GMP는 8을 반환한다. 평균은 전체 수준에, 최댓값은 가장 강한 한 위치에 민감하다. 최댓값만으로는 그 반응이 몇 번 나타났는지 알 수 없다.

### 8. CBAM에서 channel attention은 feature map에 어떻게 적용되는가?

MLP 출력들의 합에 sigmoid를 적용해 C개 계수를 얻는다. 이 벡터를 높이·너비 방향으로 펼쳐 입력에 원소별로 곱하면 원래 크기의 특징 맵이 남는다.

### 9. Spatial attention에서는 channel 방향으로 어떤 pooling을 수행하는가?

각 위치에서 채널들을 평균한 맵 하나와 최댓값을 취한 맵 하나를 만든다. 이때 pooling 방향은 채널 축이다. 두 맵을 붙여 원 논문에서는 7×7 필터로 공간 가중치를 구한다.

### 10. Spatial attention map은 feature map의 어떤 부분을 강조하는가?

주변까지 함께 보았을 때 분류에 유리한 반응이 있는 위치를 상대적으로 더 남긴다. 배경 억제를 기대할 수 있지만 이 값이 물체의 정답 마스크나 결정의 인과적 설명은 아니다.

### 11. Channel attention을 먼저 적용하고 spatial attention을 나중에 적용하는 이유는 무엇인가?

어떤 채널을 남길지 정한 결과가 위치 판단의 입력이 된다. 원 논문의 순서 비교가 채널→공간 설계를 뒷받침했다. 순서를 바꾸면 두 번째 단계가 보는 데이터도 달라진다.

### 12. CBAM이 SE block보다 확장된 점은 무엇인가?

SE는 전역 평균으로 채널을 조절한다. CBAM은 채널 계산에 최댓값도 사용하고, 위치 가중치를 계산하는 단계를 추가한다. 그래서 두 구조의 점수 차이에는 두 변경이 함께 들어간다.

### 13. CBAM을 사용하면 네트워크가 어떤 정보를 더 잘 선택할 수 있는가?

같은 특징이라도 어느 영역에서 나왔는지를 추가로 반영할 수 있다. 보행 신호에서는 구간 전체에서 쓸 채널을 고른 다음 충격이 두드러지는 시점을 더 남기는 방식으로 해석할 수 있다.

### 14. CBAM의 장점과 추가 비용은 무엇인가?

입출력 크기를 유지해 기존 블록에 넣기 쉽다. 반면 pooling, MLP, 공간 합성곱과 두 번의 곱셈이 추가된다. WISDM B3−B2는 평균 +0.21%p, 2/5 fold 상승이라 사전에 정한 개선 기준에 도달하지 못했다.
