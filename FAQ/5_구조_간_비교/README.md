# 5. 구조 간 비교 질문

[FAQ 목차로 돌아가기](../README.md)

## 코드를 읽을 때 먼저 확인할 연산

| 구조 | 연산 | 결과를 읽는 법 |
|---|---|---|
| ResNet | 덧셈 | 기존 특징에 변화량을 더한다. |
| Inception | 채널 방향 결합 | 여러 분기의 특징을 다음 층에 함께 전달한다. |
| SE / CBAM | 원소별 곱셈 | 입력별 계수로 채널 또는 위치의 반응을 조절한다. |
| Xception | 채널별 합성곱 → 1×1 합성곱 | 공간 패턴 추출과 채널 혼합을 두 단계로 계산한다. |

### 1. ResNet, SENet, CBAM은 모두 기존 CNN에 추가할 수 있는 모듈이다. 각각의 목적은 어떻게 다른가?

ResNet 블록은 입력을 출력에 더해 정보와 기울기가 흐를 경로를 만든다. SE는 채널별로, CBAM은 채널별·위치별로 계수를 곱한다. 그래서 SE나 CBAM을 residual 블록 안에 넣으면 한 블록에서 곱셈과 덧셈을 모두 볼 수 있다.

### 2. ResNet은 feature를 더 잘 선택하는 모델인가, 아니면 학습을 안정화하는 모델인가?

기본 residual 연결의 직접적인 목적은 깊은 변환을 학습하기 쉽게 하는 것이다. 별도의 선택 계수를 계산하지 않아도 입력이 출력으로 전달된다. 같은 블록에 SE나 CBAM을 넣으면 특징 재가중을 함께 수행할 수 있다.

### 3. SENet과 CBAM은 모두 attention을 사용한다. 두 방법의 차이는 무엇인가?

SE는 채널별 평균을 MLP에 넣어 채널 가중치를 만든다. CBAM은 평균과 최댓값 요약을 공유 MLP로 처리해 채널을 조절하고, 공간 가중치를 한 번 더 계산한다.

### 4. SENet은 channel attention만 사용하고, CBAM은 channel attention과 spatial attention을 모두 사용한다. 이 차이가 왜 중요한가?

어떤 채널에서 물체와 배경이 모두 강하게 반응하면 SE 계수 하나는 두 곳에 같이 곱해진다. CBAM은 위치별 계수를 추가해 그 둘을 다르게 처리할 수 있다.

### 5. Inception과 Xception은 모두 효율적인 convolution 구조를 고민한 모델이다. 두 모델의 핵심 차이는 무엇인가?

Inception은 여러 크기의 필터를 분기에 배치해 서로 다른 범위의 특징을 동시에 추출한다. Xception은 공간 필터와 채널 혼합을 분리하는 쪽으로 설계를 밀어붙였다.

### 6. Inception의 병렬 convolution과 Xception의 depthwise separable convolution은 각각 어떤 방식으로 연산 효율성을 높이는가?

Inception은 병렬화 자체보다 비싼 분기 앞에서 채널을 줄이는 병목과 분기별 폭 조절로 비용을 관리한다. Xception은 각 채널의 공간 필터 결과를 여러 출력 채널에서 다시 사용해 중복 연산을 줄인다.

### 7. 1 x 1 convolution은 Inception, Xception, SENet 계열에서 각각 어떤 역할로 사용될 수 있는가?

Inception에서는 큰 필터 앞에서 채널을 축소하고, Xception에서는 depthwise 결과를 섞는다. SE에서는 GAP 뒤 1×1×C 벡터에 쓰는 두 Dense 층을 1×1 합성곱으로도 구현할 수 있다. 이 경우 결과는 원래 특징에 곱할 채널 계수다.

### 8. Channel attention과 1 x 1 convolution은 모두 channel을 다룬다. 둘의 차이는 무엇인가?

1×1 합성곱은 학습한 행렬 W로 각 위치의 벡터 x를 Wx로 변환해 채널을 섞는다. SE 계수는 현재 샘플에서 계산되며 결과는 채널별 곱 g(x)⊙x이다. 계수를 만드는 과정에서 다른 채널을 참조해도 마지막 적용은 각 채널 안에서 이루어진다.

### 9. Skip connection과 attention module은 모두 성능 향상에 기여하지만, 해결하는 문제는 어떻게 다른가?

지름길은 입력이 블록을 우회하도록 해 최적화를 돕는다. attention은 현재 입력에서 어떤 반응을 유지할지 조절한다. WISDM B2에서는 변환한 특징에 SE 가중치를 곱한 뒤 입력을 더해 두 아이디어를 함께 썼다.

### 10. CNN 모델에서 성능 향상을 위해 사용되는 전략을 크게 나누면 어떤 것들이 있는가?

이번 범위에서는 ① 학습 경로 개선(ResNet), ② 여러 범위의 특징 추출(Inception), ③ 입력별 특징 선택(SE·CBAM), ④ 연산 분해와 경량화(Xception 계열)로 정리했다. 전략마다 목표가 달라 성능은 F1, 비용은 파라미터와 실제 추론시간으로 각각 확인한다.
