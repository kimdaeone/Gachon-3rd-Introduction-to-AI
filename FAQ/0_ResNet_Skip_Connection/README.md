# 0. ResNet / Skip Connection

[FAQ 목차로 돌아가기](../README.md)

## 블록의 두 경로

```mermaid
flowchart LR
 X[입력 x] --> F[합성곱 두 층]
 F --> A((덧셈))
 X --> A
 A --> R[ReLU]
```

덧셈에는 두 입력의 크기가 같아야 한다. 한 위치에서 $x=3$, $F(x)=-1$이면 블록 출력은 $\mathrm{ReLU}(3-1)=2$다. 여기서 $x$는 블록에 들어온 특징이고 $F(x)$는 합성곱 경로의 출력이다.

### 1. ResNet이 등장한 배경은 무엇인가?

깊이를 늘리면 더 복잡한 함수를 표현할 수 있다. 그런데 원 논문에서 일반 CNN을 20층에서 56층으로 늘리자 훈련 오차까지 커졌다. ResNet은 깊어진 모델도 얕은 모델이 이미 찾아낸 해를 쉽게 유지하도록 설계했다.

### 2. 네트워크를 단순히 깊게 쌓으면 왜 성능이 오히려 떨어질 수 있는가?

추가된 층들이 입력을 그대로 통과시키기만 해도 얕은 모델의 성능을 재현할 수 있다. 실제 최적화에서는 여러 합성곱이 동시에 그런 가중치를 찾기 어렵다. 훈련 오차부터 커진다면 과적합만으로는 설명하기 어렵다.

### 3. Vanishing gradient 문제란 무엇인가?

역전파는 층마다 미분값을 곱해 앞쪽으로 전달한다. 단순한 예로 0.5를 열 번 곱하면 약 0.001이다. 앞쪽 층이 받는 기울기가 이렇게 작아지면 그 층의 가중치가 거의 갱신되지 않는다.

### 4. Skip connection이란 무엇인가?

블록의 입력에서 출력 쪽으로 중간 층을 건너가는 연결이다. ResNet의 기본 블록에서는 합성곱 경로와 지름길 경로가 다시 만나고, 같은 위치의 값을 더한다.

### 5. Skip connection은 입력 (x)를 어떤 방식으로 다음 블록에 전달하는가?

크기가 맞으면 입력 $x$를 그대로 보낸다. 높이·너비나 채널 수가 달라지면 stride와 1×1 합성곱 등을 사용해 덧셈이 가능한 크기로 맞춘다. WISDM A1에서는 더한 뒤 pooling을 해서 블록 안에서는 별도 변환이 필요 없었다.

### 6. ResNet의 기본 아이디어를 수식으로 표현하면 어떻게 되는가?

기본식은 $y=x+F(x)$이다. 여기서 $F$는 블록의 가중치가 학습하는 변환이다. 우리 A1처럼 덧셈 뒤 ReLU가 있는 구현의 실제 출력은 $\mathrm{ReLU}(x+F(x))$이다.

### 7. 일반적인 CNN 블록이 (H(x))를 직접 학습하는 것과, ResNet이 (F(x)=H(x)-x)를 학습하는 것의 차이는 무엇인가?

일반 블록은 필요한 출력 $H(x)$ 전체를 만든다. residual 블록은 입력이 이미 제공되므로 $H(x)-x$에 해당하는 변화량을 만들면 된다. 학습 데이터에 잔차 정답을 따로 만드는 과정은 없고, 최종 분류 손실로 두 경로를 포함한 모델을 학습한다.

### 8. Residual learning이 학습을 쉽게 만드는 이유는 무엇인가?

덧셈 단계에서 입력을 유지하려면 잔차 경로가 0을 출력하면 된다. 여러 합성곱을 거쳐 입력 전체를 복원하는 것보다 항등 변환을 표현하기 쉽다.

### 9. Skip connection이 gradient flow에 주는 장점은 무엇인가?

덧셈 직후까지의 미분은 $I+J_F(x)$이다. 여기서 $I$는 항등 경로의 미분, $J_F$는 잔차 경로의 야코비안이다. 잔차 경로에서 기울기가 작아져도 항등 경로로 역전파될 수 있다. 덧셈 뒤 활성화가 있으면 그 미분도 적용된다.

### 10. ResNet은 깊은 네트워크에서 어떤 문제를 해결하기 위해 제안되었는가?

직접 겨냥한 현상은 깊이를 늘렸을 때 훈련 성능까지 나빠지는 degradation이다. 우리 A1과 A0는 모두 84,870개 파라미터였고 A1의 개발 Macro F1은 0.49%p 낮아, 얕은 모델에서 residual만 추가한 효과는 사전 기준으로 구별하기 어려웠다.
