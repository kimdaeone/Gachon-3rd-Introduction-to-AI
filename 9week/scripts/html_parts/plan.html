스마트폰으로 측정한 3축 가속도에서 걷기, 뛰기, 계단 오르기, 계단 내려가기, 앉기, 서기를 구분한다. 학습에 참여하지 않은 사람에게도 잘 작동하는지 확인하고, CNN 구조를 바꿨을 때 얻는 성능을 파라미터 수와 CPU 추론 시간과 함께 평가했다.

CNN 간에는 데이터 정제, 사용자 분할, 학습 설정, 평가 지표를 공통으로 적용했다. 같은 데이터 분할에서 통계 특징을 쓰는 Random Forest(RF)도 별도 참조선으로 학습했다.

학습 전에 정한 판정 기준

같은 fold 안에서 seed 세 개의 Macro F1을 평균한 뒤, 비교할 두 모델의 차이를 계산한다. 예를 들어 0.890에서 0.895로 오르면 +0.5%p다. 평균 변화와 변화 방향이 일치하는 fold 수를 함께 본다.

판정조건

위 기준은 이 실험에서 의미 있게 볼 변화 폭을 정하기 위한 실용 규칙이다. 통계적 유의성이나 비열등성을 검정하는 절차는 별도로 수행하지 않았다. Macro F1 0.90은 각 모델의 절대 수준을 살펴보는 참고선으로 사용했다.

실행 범위와 실제 진행

  1. 필수 실험 완료. A0, A1, A2, B1, B2, B3, B4에서 각각 5 fold × 3 seed를 실행했다. CNN 105회와 별도 RF 15회다.
  2. 선택 실험 보류. B4에 SE·CBAM을 붙이는 B5·B6와 A0에 SE·Depthwise·CBAM을 적용하는 A3·A4·A5는 추가 75회의 학습이 필요했다. 확보한 GPU 시간을 필수 실험과 최종 학습에 배정했다.
  3. 조건부 실험 미실행. B3가 B2보다 사전 기준상 개선되면 CBAM의 시간 attention을 제거한 B3-C를 비교할 계획이었다. 평균 +0.21%p와 2/5 fold 상승으로 조건을 충족하지 않았다. B6-C에도 같은 원칙을 적용했다.
  4. 최종 평가 완료. 개발 평균 Macro F1이 가장 높은 CNN을 선택하고, 동점이면 파라미터 수와 모델명 순으로 결정하기로 했다. A2를 선택하고 A0와 RF를 함께 고정했다. 세 모델을 개발 사용자 30명으로 seed별 재학습한 뒤 보류 사용자에게 총 9회 평가했다.
