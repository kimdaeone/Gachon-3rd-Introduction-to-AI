# WISDM 1단계 개발 검증 종합

필수 CNN 7개 구조의 사용자 독립 교차검증 105회와 RF 참조선 15회를 비교한다. 보류 테스트의 예측값과 지표는 사용하지 않았다. 필수 7개 구조 중 개발 평균 Macro F1 기준 상위 CNN은 **A2**(0.8964)다.

## 실험과 집계

WISDM v1.1의 개발 사용자 30명, 5개 fold, seed 0·1·2를 사용했다. 각 fold에서 학습 사용자는 24명, 검증 사용자는 6명이다. 개발 검증 윈도우 6,430개의 정답과 사용자 순서, CNN의 학습 사용자 기반 표준화 값, 저장 Accuracy와 Macro F1을 대조했다. 데이터 SHA-256은 `e573791269aab4a629721cf04b6031b7cbf8e14261cd2bc86e65887a2bc592d7`다.

fold별로 seed 3개의 지표를 먼저 평균했다. 표의 표준편차는 fold 5개의 표본 표준편차다. F1 0.90은 절대 수준 참고선이다.

A2의 RF 대비 개발 Macro F1 차이는 평균 +12.80%p이며 5/5 fold에서 높았다. RF는 같은 사용자·검증 윈도우의 통계 특징 모델이다. CNN에서는 검증 Macro F1로 epoch를 선택했고 RF에는 이 과정이 없었다.

## Q1·Q2·Q3의 짝지은 비교

차이는 같은 fold의 Macro F1 차이(%p)다. 평균 차이 +0.5%p 이상 및 4/5 fold 이상 상승이면 개선, −0.5%p 이하 및 4/5 fold 이상 하락이면 악화로 판정했다. 그 외에는 사전 기준상 구별 불가다. 표시는 소수점 둘째 자리로 반올림했고 판정은 반올림 전 값으로 했다.

### Q1의 상호작용

일반 합성곱과 Inception에서 residual을 추가했을 때의 차이를 `(B1−A2)−(A1−A0)`로 비교했다. 양수일수록 이 구현의 Inception에서 residual 추가 이득이 컸다는 관측이다. 아래 값은 %p이며 보조 분석으로 보고한다. Inception을 도입하면 파라미터 수와 수용 영역도 달라진다.

### Q2의 attention 비교

B2−B1 및 B3−B1은 각각 SE와 CBAM을 추가한 구현의 전체 효과다. B3−B2는 평균 +0.21%p로 사전 판정은 **구별 불가**다. 두 구조는 채널 attention 계산에서도 차이가 있어 시간 attention의 기여는 B3와 채널 attention만 남긴 B3-C를 직접 비교해야 분리할 수 있다.

### Q3와 효율

B4의 B1 대비 Macro F1 손실은 +0.38%p다. 파라미터 수는 B1 36,806개, B4 15,878개이며 B1 기준 감소율은 56.9%다. 손실이 1.0%p 이내이고 파라미터도 감소할 때 적용하는 사전 판정은 **경량화 유지**다.

표의 학습 시간은 `model.fit` 합계이며 총 126.7분이다. 런타임과 선택 epoch가 달라질 수 있다. 파라미터 수만으로 CPU 지연이나 전력 사용량을 추정할 수 없다.

AMD Ryzen 7 7730U with Radeon Graphics에서 TensorFlow 2.22.0-rc0로 측정했다. 스레드 1개와 batch 1에서 모델별 워밍업 50회 후 200회씩 5차례 실행했다. 아래 수치는 출력 변환을 포함한 호출 1,000회의 중앙값과 사분위수다. B4−B1의 지연 중앙값 차이는 -0.008ms(-1.2%)다. [CPU 측정 기록](../final/cpu_latency.json) · [호출별 시간](../final/cpu_latency_calls.csv)

## 테스트 열람 전 범위와 후보 기록

- 2단계(B5·B6·A3·A4·A5)는 보류한다. 무료 Colab GPU 세션을 필수 1단계와 확정 후보의 최종 학습에 배정했고, 후속 구조의 별도 실행 예산은 확보하지 않았다. 같은 반복 설계에서는 75회 추가 학습이 필요하다.
- 3단계 B3-C의 ‘B3가 B2보다 좋은 경우’는 계획서의 사전 개선 규칙을 적용했다. 발동 조건이 충족되지 않아 B3-C를 실행하지 않는다. B6-C에도 같은 발동 조건을 적용한다.

완료된 CNN 구조 중 개발 평균 Macro F1, 파라미터 수, 모델명 순서로 후보를 선택했다. A2 구조를 후보로 고정하고 A0와 RF를 참조선에 포함한다. CNN은 개발 30명으로 표준화를 다시 계산하고 15개 최적 epoch의 중앙값을 반올림해 고정한다.

| 모델 | 최종 학습 재설정 |
| --- | --- |
| A2 | 15 epoch × seed 0·1·2 |
| A0 | 13 epoch × seed 0·1·2 |
| RF | 기존 특징과 모델 설정, seed 0·1·2 |

## 해석의 한계

검증 Macro F1로 epoch와 모델 구조를 선택했으므로 개발 점수에는 선택 편향이 있을 수 있다. fold 사이 학습 사용자가 겹치고 seed는 같은 검증 사용자를 반복하므로 fold 표준편차를 신뢰구간으로 사용하거나 15회를 독립 표본으로 취급할 수 없다. 이 비교는 통계적 유의성이나 비열등성 검정을 수행하지 않는다. 데이터 품질과 라벨 분포를 분석할 때 전체 데이터를 살펴봤고, 보류 사용자는 모델 학습과 개발 검증에서 제외했다. 보류 사용자 6명과 통제된 수집 환경은 다른 기기, 휴대 위치, 일상 환경으로의 일반화에 한계를 둔다.
