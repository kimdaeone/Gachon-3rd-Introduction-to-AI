# WISDM 1단계 후속 실행 계획

2026-11-16 기준. 모델은 신경망 구조 하나이고, 학습 1회는 해당 구조를 새 가중치로 초기화해 학습하는 실행 하나다. 15회는 15 epoch가 아니라 5 fold × 3 seed이다.

## 범위와 순서

필수 7개 구조에서 총 105회 학습한다. A0 15회는 완료됐으며 A1부터 B4까지 90회가 남았다. RF는 별도 참조선으로 이 수에 포함하지 않는다.

| 순서 | 모델 | 구조 | 주요 비교 |
|---|---|---|---|
| 완료 | A0 | 기본 CNN | 기준점 |
| 1 | A1 | A0 + residual | A1−A0 |
| 2 | A2 | Inception | A2−A0 |
| 3 | B1 | Inception + ResNet | B1−A2, A0·A1과 보조 비교 |
| 4 | B2 | B1 + SE | B2−B1 |
| 5 | B3 | B1 + CBAM | B3−B1, B3−B2 |
| 6 | B4 | Depthwise Inception + ResNet | B4−B1, 파라미터 감소와 성능 손실 |

## 모델마다 완료할 작업

1. 구조 차이와 데이터·분할·학습 조건을 확인한다.
2. Colab T4에서 5 fold × seed 0·1·2를 실행한다. 실행마다 최대 100 epoch, 검증 Macro F1 patience 12, 최적 가중치 복원이다.
3. 실행별 예측·학습 곡선·표준화 값·가중치·환경·진행 기록을 저장하고 PC와 Drive로 회수한다.
4. 15개 고유 fold/seed와 보류 사용자 제외 여부를 확인한다. 예측값으로 Accuracy·Precision·Recall·F1을 다시 계산해 저장 지표와 대조한다.
5. 독립 연구보고서에 데이터·학습 설정·학습 곡선·분류지표·혼동행렬·fold/seed/사용자 분석·비교·한계·다음 실험을 작성한다.
6. 결과와 보고서를 Drive에 저장하고 모델별로 GitHub에 커밋·푸시한 후 다음 모델로 진행한다.

진행 기록은 `runs/{모델}_progress.json`, 최종 보고서는 `reports/`에 둔다. 실행 중인 모델을 완료로 표시하지 않는다. 연결이 끊기면 원격 학습 상태를 먼저 확인하고 완료 조합을 재학습하지 않는다. 오류나 저장 실패가 있으면 다음 모델로 넘어가지 않는다. 작업 종료 시 GPU를 해제한다.

## 비교와 후속 판단

주 지표는 seed 3개를 먼저 평균한 fold 5개의 Macro F1 평균과 표준편차다. 같은 fold끼리 비교하고, 평균 +0.5%p 이상이면서 4/5 fold 이상 개선일 때 사전 개선 규칙을 충족한 것으로 판정한다. B4는 계획서의 성능 손실 허용폭 1.0%p와 파라미터 수를 함께 확인한다. 통계적 유의성을 뜻하지 않는다.

A0는 순수 학습시간 합계 707.6초였다. 다른 구조의 시간은 실제 실행으로 확인하며 이 값의 단순 배수로 완료 시간을 확정하지 않는다. 필수 구조 결과와 자원 사용을 검토한 뒤 2단계 B5·B6·A3·A4·A5 확장 여부를 결정한다. 3단계 시간 attention 제거 실험은 계획서의 조건을 충족할 때 진행한다. 테스트 6명은 후보와 설정을 고정한 뒤 최종 평가에서만 사용한다.
