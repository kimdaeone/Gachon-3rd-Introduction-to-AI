## 1. 무엇을 알아내려는가

> 기본 CNN에 부품(ResNet, Inception, SE, CBAM, Depthwise)을 붙였을 때, **학습에 참여하지 않은 사람**의 행동을 더 잘 맞히게 되는가? 그 이득은 추가 계산 비용만큼 가치가 있는가?

| 연구 질문 | 비교 |
|---|---|
| Q1. 여러 시간 규모(Inception)와 지름길(ResNet)을 합치면 좋아지는가? | A0·A1·A2 vs B1 |
| Q2. 그 위에 attention(SE, CBAM)을 더하면 더 좋아지는가? | B1 vs B2·B3 |
| Q3. 합성곱을 가볍게(Depthwise) 바꿔도 성능이 유지되는가? | B1 vs B4 |

- **주목적:** 새 사용자에 대한 Macro F1 개선 여부 판정
- **부목적:** 성능 대비 계산 비용(파라미터 수, 추론시간) 비교
- **결과의 형태:** "1등 모델"이 아니라 "어떤 부품이 어떤 조건에서 도움이 되었고, 비용에 비해 충분했는가". 효과가 없다는 결과도 유효한 결과다.

**고정하는 것:** 데이터, 정제·전처리, 사람 분할, 학습 방법(optimizer, epoch, batch), 평가 지표
**바꾸는 것:** 신경망 구조만

- **주의:** 17명은 일부 행동이 없음. Sitting 보유자 23명, Standing 보유자 24명

## 3. 평가 설계

```
36명
├─ 테스트 6명  : 처음에 고정, 최종 후보 평가 때만 1회 사용
└─ 개발 30명   : 6명씩 5묶음 → 5-fold 교차검증 (학습 24명 / 검증 6명)
```

- **사람 단위 분할:** 한 사람의 데이터가 학습과 평가에 동시에 들어가지 않게 한다.
- **분할 조건:** 테스트와 각 검증 묶음에 Sitting·Standing 보유자가 고르게 들어가게 한다.
- **윈도우 간격(stride):** 학습 64(절반 겹침), 검증·테스트 128(겹치지 않음)
- **표준화:** 학습 사람의 데이터로만 평균·표준편차를 계산한다.
- **지표:**
  - 주 지표: Macro F1(6개 행동을 같은 비중으로 평균)
  - 보조 지표: Accuracy, 행동별 recall, 사람별 성능, 파라미터 수, CPU 추론시간
- **반복:** fold 5개 × seed 3개

## 4. 실험할 모델

"모델" = 신경망 구조 설계 하나(실험 조건 하나). 모델 1개를 fold × seed만큼 학습한다.

| 단계 | 모델 | 구조 | 답하는 질문 |
|---|---|---|---|
| **1 (필수)** | A0 | 기본 CNN | 기준점 |
| | A1 | A0 + residual | Q1 |
| | A2 | Inception | Q1 |
| | B1 | Inception + ResNet | Q1, Q2, Q3의 기준 |
| | B2 | B1 + SE | Q2 |
| | B3 | B1 + CBAM | Q2 |
| | B4 | Depthwise Inception + ResNet | Q3 |
| 2 (시간이 허락하면) | B5, B6 | B4 + SE, B4 + CBAM | attention 효과가 경량화에 따라 달라지는가 |
| | A3, A4, A5 | A0 + SE / Depthwise / CBAM | 부품 단독 효과 |
| 3 (조건부) | B3-C, B6-C | CBAM에서 시간 attention 제거 | B3가 B2보다 좋을 때만: 시간 attention의 기여 분리 |

1단계 학습 횟수: 7개 × 5 fold × 3 seed = 105번. A0 학습 시간을 실측한 뒤 2단계 진행 여부를 정한다.

## 5. 판정 규칙 (학습 전에 확정)

비교하는 두 모델을 같은 fold끼리 짝지어 Macro F1 차이를 구한다(seed 3개 평균).

| 판정 | 조건 (2026-11-09 확정) |
|---|---|
| **개선** | 차이의 평균 ≥ **+0.5%p** **이고** 5개 fold 중 4개 이상에서 개선 |
| **악화** | 차이의 평균 ≤ **−0.5%p** **이고** 5개 fold 중 4개 이상에서 악화 |
| **구별 불가** | 그 외 |
| **경량화 유지** (Q3) | B1 대비 Macro F1 손실 ≤ **1.0%p** **이고** 파라미터 감소 |

**기준값의 근거**
- 0.5%p: 이 연구에서 사전에 정한 실용적인 Macro F1 개선폭이다. Macro F1은 클래스별 precision·recall에 의존하므로 추가 정답 개수로 환산할 수 없다. 이 문턱이 통계적 유의성을 보장하지 않는다.
- 1.0%p: 파라미터 감소 시 허용하는 평균 Macro F1 손실의 사전 약속이다. 오분류율 1% 증가와 같지 않으며, 통계적 비열등성 검정을 뜻하지 않는다.
- 학습 결과를 보고 이 기준을 바꾸지 않는다.

**절대 수준 참고선:** 교수님 기대치는 Macro F1 0.90 이상이다. 판정은 위의 상대 규칙으로 하고, 각 모델이 0.90에 도달했는지는 함께 보고한다. 다른 논문의 수치(예: Random Forest 0.87)는 평가 방식이 다를 수 있다(무작위 분할이면 같은 사람이 학습·평가에 섞인다). 그래서 평가 방식을 확인한 뒤에만 비교한다.
- 테스트 6명 결과는 개발 단계의 판정을 확인하는 용도로만 사용하고, 결과를 보고 판정 규칙을 바꾸지 않는다.

- **실생활 환경 일반화:** WISDM은 통제된 실험실 조건에서 수집했으므로, 다른 기기나 휴대 위치에서의 성능은 보장하지 않는다.

## 9. 학습 전 검토 및 보완 (2026-11-16)

### 평가의 해석
- 검증 fold의 Macro F1로 EarlyStopping(최대 100 epoch, patience 12)을 적용하고 같은 fold를 평가한다. 따라서 이 점수는 **모델·epoch 선택용 개발 점수**이며, 편향 없는 최종 일반화 추정치라고 주장하지 않는다. RF에는 같은 epoch 선택 과정이 없으므로 개발 점수 비교에는 이 차이도 명시한다.
- 5-fold는 학습 사람이 서로 겹친다. 15회 결과를 독립 표본 15개로 취급하지 않는다. seed 3개를 먼저 평균한 뒤 fold 5개의 평균과 표준편차를 보고한다. 표준편차는 신뢰구간이 아니다.
- Macro F1은 행동별 비중을 같게 하지만 사람별 비중까지 같게 만들지는 않는다. 사람별 정확도와 그 단순 평균, 최저값도 함께 보고한다. 어려운 사람을 점수 때문에 제외하지 않는다.
- 개선/악화/구별 불가는 사전 실용 판정이며 통계적 유의성 판정이 아니다. 여러 구조를 비교한 뒤 나온 최고 점수에는 선택 편향이 있을 수 있다.

### 구조 효과와 효율의 해석
- A0/A1과 A2/B1은 파라미터 수와 수용 영역도 다르다. Inception 비교는 이 구현 전체의 효과이며, 파라미터 수를 통제한 순수 효과로 해석하지 않는다.
- residual의 효과는 A1−A0와 B1−A2를 각각 비교한다. B1이 가장 높다는 이유만으로 결합의 상승효과를 주장하지 않는다. 상승효과는 fold별 `(B1−A2)−(A1−A0)`도 보조적으로 확인한다.
- CBAM과 SE는 채널 attention 계산도 다르다. B3−B2만으로 시간 attention 효과를 분리했다고 말하지 않는다.
- 파라미터 감소가 실제 속도 향상을 보장하지 않는다. CPU 추론시간은 최종 비교 단계에서 같은 PC·TensorFlow 버전·스레드 수·batch 1·입력 shape로 측정한다. 모델별 워밍업 50회 후 200회 호출을 5차례 측정하고 출력 변환까지 포함한 중앙값과 사분위 범위를 보고한다. 로딩·전처리는 제외한다. 서로 다른 Colab 런타임의 학습시간은 참고만 한다.

### 최종 테스트 절차
1. 개발 5-fold 평균 Macro F1이 가장 높은 구조를 후보로 선택한다. 동점이면 파라미터가 적은 구조, 그래도 같으면 모델명 순으로 정한다. A0와 RF를 참조선으로 함께 고정한다. 선택 결과와 설정을 테스트 열람 전에 기록한다.
2. CNN별 15회 best epoch의 중앙값을 반올림(0.5는 올림)하여 최종 학습 epoch를 고정한다. 개발 30명으로 표준화 통계를 다시 계산하고 30명 전체로 seed 0·1·2를 각각 재학습한다. 테스트를 EarlyStopping에 사용하지 않는다. RF는 기존 설정을 유지하고 개발 30명으로 다시 학습한다.
3. 고정한 테스트 사용자 `[6, 21, 24, 27, 29, 34]`에 대해 정해 둔 모든 모델·seed를 한 번의 최종 평가 단계에서 평가한다. seed별 점수와 평균·표준편차, 행동별 recall, 사람별 정확도를 보고한다. 가장 좋은 seed만 골라 보고하지 않는다.
4. 테스트를 보고 구조·epoch·정제·판정 기준을 수정하지 않는다. 테스트는 6명뿐이므로 넓은 사용자 집단에 대한 결론에는 한계가 있다. 이미 전체 데이터의 품질·라벨 분포를 살펴봤다는 사실도 보고한다.

### 실행 및 저장
- Adam(0.001), batch 64, 최대 100 epoch, 검증 Macro F1 조기 종료(patience 12, 최적 가중치 복원)를 7개 CNN에 동일 적용한다. seed는 `[0, 1, 2]`이다.
- 03→09 순서로 Colab GPU에서 실행한다. 각 fold/seed 완료 직후 결과를 저장하며 재실행 시 완료한 조합을 건너뛴다. 중단된 조합은 처음부터 재실행한다.
- 학습 곡선, 검증 정답·예측·사용자, 표준화 값, 최적 가중치, 데이터 SHA-256, 분할·학습 설정·라이브러리 버전을 보존한다. 코드·구조를 바꾸면 이전 결과를 별도 보관하고 새로 실행한다.
- 15개 고유 fold/seed 조합이 모두 있어야 정식 요약·모델 비교를 허용한다. GPU가 연결되지 않은 Colab에서는 학습을 중단한다.
