## 1. 무엇을 알아내려는가

> 기본 CNN에 부품(ResNet, Inception, SE, CBAM, Depthwise)을 붙였을 때, **학습에 참여하지 않은 사람**의 행동을 더 잘 맞히게 되는가? 그 이득은 추가 계산 비용만큼 가치가 있는가?

| 연구 질문 | 비교 |
|---|---|
| Q1. 여러 시간 규모(Inception)와 지름길(ResNet)을 합치면 좋아지는가? | A0·A1·A2 vs B1 |
| Q2. 그 위에 attention(SE, CBAM)을 더하면 더 좋아지는가? | B1 vs B2·B3 |
| Q3. 합성곱을 가볍게(Depthwise) 바꿔도 성능이 유지되는가? | B1 vs B4 |

- **주목적:** 새 사용자에 대한 Macro F1 개선 여부 판정
- **부목적:** 성능 대비 계산 비용(파라미터 수, 추론시간) 비교
- **결과의 형태:** "1등 모델"이 아니라 "어떤 부품이 어떤 조건에서 도움이 되었고, 비용에 비해 충분했는가". 효과가 없다는 결과도 유효한 결과다.

**고정하는 것:** 데이터, 정제·전처리, 사람 분할, 학습 방법(optimizer, epoch, batch), 평가 지표
**바꾸는 것:** 신경망 구조만

## 2. 데이터

- **WISDM v1.1 raw:** 36명, 6개 행동(Walking, Jogging, Upstairs, Downstairs, Sitting, Standing), 휴대폰 3축 가속도, 20Hz
- **입력:** 128 샘플(약 6.4초) × 3축 = `(128, 3)` 윈도우 1개 → 행동 1개 예측
- **주의:** 17명은 일부 행동이 없음. Sitting 보유자 23명, Standing 보유자 24명

### 정제 정책 (제안 = 정책 3)

| 문제 | 원본에서 확인한 사례 | 처리 |
|---|---|---|
| 완전히 같은 레코드가 반복됨 | 66,820건. 사용자 19의 Jogging 12,314건은 세션 통째 복사 | 처음 것만 남기고 삭제 |
| timestamp 0, 가속도 0,0,0 | 12,845건, 그중 11,848건이 Jogging | 삭제 (중력 때문에 0,0,0은 불가능) |
| 측정 중간의 긴 공백 | 예: 사용자 33 Jogging 14.9초 공백 | 1초를 넘는 공백에서 구간을 끊음 |
| 구간이 128 샘플보다 짧음 | — | 윈도우를 만들 수 없으므로 버림 |

시뮬레이션 결과: 행동별 원본의 **88~97%가 유지**되고, 겹치지 않는 윈도우 약 7,680개가 남는다(Sitting 414, Standing 351). 이상 지점마다 끊기만 하는 방식은 Sitting이 7.6%만 남아 사용하지 않는다.

## 3. 평가 설계

```
36명
├─ 테스트 6명  : 처음에 고정, 최종 후보 평가 때만 1회 사용
└─ 개발 30명   : 6명씩 5묶음 → 5-fold 교차검증 (학습 24명 / 검증 6명)
```

- **사람 단위 분할:** 한 사람의 데이터가 학습과 평가에 동시에 들어가지 않게 한다.
- **분할 조건:** 테스트와 각 검증 묶음에 Sitting·Standing 보유자가 고르게 들어가게 한다.
- **윈도우 간격(stride):** 학습 64(절반 겹침), 검증·테스트 128(겹치지 않음)
- **표준화:** 학습 사람의 데이터로만 평균·표준편차를 계산한다.
- **지표:**
  - 주 지표: Macro F1(6개 행동을 같은 비중으로 평균)
  - 보조 지표: Accuracy, 행동별 recall, 사람별 성능, 파라미터 수, CPU 추론시간
- **반복:** fold 5개 × seed 3개

## 4. 실험할 모델

"모델" = 신경망 구조 설계 하나(실험 조건 하나). 모델 1개를 fold × seed만큼 학습한다.

| 단계 | 모델 | 구조 | 답하는 질문 |
|---|---|---|---|
| **1 (필수)** | A0 | 기본 CNN | 기준점 |
| | A1 | A0 + residual | Q1 |
| | A2 | Inception | Q1 |
| | B1 | Inception + ResNet | Q1, Q2, Q3의 기준 |
| | B2 | B1 + SE | Q2 |
| | B3 | B1 + CBAM | Q2 |
| | B4 | Depthwise Inception + ResNet | Q3 |
| 2 (시간이 허락하면) | B5, B6 | B4 + SE, B4 + CBAM | attention 효과가 경량화에 따라 달라지는가 |
| | A3, A4, A5 | A0 + SE / Depthwise / CBAM | 부품 단독 효과 |
| 3 (조건부) | B3-C, B6-C | CBAM에서 시간 attention 제거 | B3가 B2보다 좋을 때만: 시간 attention의 기여 분리 |

1단계 학습 횟수: 7개 × 5 fold × 3 seed = 105번. A0 학습 시간을 실측한 뒤 2단계 진행 여부를 정한다.

## 5. 판정 규칙 (학습 전에 확정)

비교하는 두 모델을 같은 fold끼리 짝지어 Macro F1 차이를 구한다(seed 3개 평균).

| 판정 | 조건 (2026-11-09 확정) |
|---|---|
| **개선** | 차이의 평균 ≥ **+0.5%p** **이고** 5개 fold 중 4개 이상에서 개선 |
| **악화** | 차이의 평균 ≤ **−0.5%p** **이고** 5개 fold 중 4개 이상에서 악화 |
| **구별 불가** | 그 외 |
| **경량화 유지** (Q3) | B1 대비 Macro F1 손실 ≤ **1.0%p** **이고** 파라미터 감소 |

**기준값의 근거**
- 0.5%p: 검증 윈도우 약 1,300개 중 약 6~7개를 더 맞히는 정도. 02에서 epoch 사이 흔들림이 수 %p였으므로, seed 3개를 평균한 뒤에도 이보다 작은 차이는 의미를 두기 어렵다.
- 1.0%p: 경량화로 파라미터가 크게(수십 %) 줄어든다면 윈도우 100개 중 1개를 더 틀리는 정도는 감수할 수 있다는 실용적 선택이다. 이론적으로 정해진 값이 아니라 이 연구의 사전 약속이다.
- 학습 결과를 보고 이 기준을 바꾸지 않는다.

**절대 수준 참고선:** 교수님 기대치는 Macro F1 0.90 이상이다. 판정은 위의 상대 규칙으로 하고, 각 모델이 0.90에 도달했는지는 함께 보고한다. 다른 논문의 수치(예: Random Forest 0.87)는 평가 방식이 다를 수 있다(무작위 분할이면 같은 사람이 학습·평가에 섞인다). 그래서 평가 방식을 확인한 뒤에만 비교한다.
- 테스트 6명 결과는 개발 단계의 판정을 확인하는 용도로만 사용하고, 결과를 보고 판정 규칙을 바꾸지 않는다.

## 8. 이번 연구의 범위 밖

- **Transformer·RNN 등 다른 계열 구조:** 연구 질문이 "CNN 부품의 효과"이므로 본 실험에 넣지 않는다. 필요하면 06 이후 같은 평가 설계로 확장 실험을 한다.
- **실생활 환경 일반화:** WISDM은 통제된 실험실 조건에서 수집했으므로, 다른 기기나 휴대 위치에서의 성능은 보장하지 않는다.
- **클래스 가중치, 데이터 증강, 윈도우 길이 변경:** 구조 비교가 끝난 뒤 별도 실험으로 다룬다.
